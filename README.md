# Import Drive - Locação de Carros Importados

Projeto do Checkpoint 6 de Web Development (FIAP - 1ESPG) desenvolvido com **React**, **Vite** e **Tailwind CSS**.

## Tecnologias

- React 19
- Vite
- Tailwind CSS 4 (`@tailwindcss/vite`)
- React Router DOM

## Estrutura de pastas

```
src/
├── assets/        # imagens dos carros
├── components/    # Navbar, Footer e Card
├── css/           # estilos globais e variáveis
├── data/          # catálogo de carros
├── pages/         # Home, Carros, Contato, Login e Error
├── App.jsx        # configuração das rotas
└── main.jsx
```

## Como executar

```bash
npm install
npm run dev
```

## Fluxo de trabalho

- `main`: versão final do projeto
- `dev`: integração das tarefas
- `feature/*`: uma branch por tarefa, com Pull Request para `dev`
